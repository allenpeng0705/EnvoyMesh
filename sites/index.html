Knowledge Base & Vault

EnvoyMesh includes a powerful local-first knowledge base with RAG indexing. Your documents, notes, and files are indexed for semantic search and injected into AI prompts as context. Public knowledge is shared across the mesh — private data never leaves your node.

  • Import any file type — Markdown, PDF, Word, images, and more
  • RAG indexing with vector + lexical + hybrid search modes
  • Per-item sensitivity labels: public, friends, or private
  • Public items are queryable by all EnvoyMesh peers via knowledge.query
  • Agent context: vault snippets automatically injected into LLM prompts

🔌 Plugin Architecture — Bring Your Own Knowledge Base

EnvoyMesh designed a knowledge base plugin system. The built-in vault always works standalone, but plugins can enrich it with extra capabilities. The first plugin available is Obsidian — open the same vault directory in Obsidian and get wiki-links, backlinks, graph view, tags, templates, frontmatter, and daily notes, all synced with your EnvoyMesh knowledge base.

How It Works

EnvoyMesh follows a layered security architecture — each component has a clear boundary and responsibility.

🌐

Diplomat (Network)

libp2p connections, message parsing, rate limiting

🔑

Identity & Bonds

Signature verification, trust tiers, policy enforcement

⚙️

Workflows & Agent Core

Task execution, AI routing, workflow management

📦

Vault API

Knowledge retrieval, document indexing, secure storage

🧠

Sandboxed Brain

Local/remote model execution, semantic firewall

Security Pipeline

Every message goes through four checks before delivery:

  1. 1 Is it really from you? (signed with your Ed25519 key)
  2. 2 Do I trust you? (trust tiers: blocked, public, referred, direct)
  3. 3 Is this message allowed? (policy engine — what can this sender do?)
  4. 4 Has it been seen before? (no replays, no duplicates)

Security by Design

Built with security as the first priority, not an afterthought.

🔑

🛡️

📝

🔒

Semantic Firewall

🚫

Only approved data and capabilities accessible.

🔄

Key Rotation

Prefer to build from source? Clone the repo and run EnvoyMesh in minutes.

cd EnvoyMesh
./scripts/setup.sh

# Run
npm run node:dev # Start the P2P node
npm run social:dev # Open http://localhost:5173
