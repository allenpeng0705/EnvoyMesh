Review steps

  1. Install EnvoyHome from TestFlight / App Store or Play Console.
  2. Open the app → Pair → scan the QR above (or paste the URI).
  3. Allow Camera (and on iOS, Local Network if prompted).
  4. After pair: open Chat → send “hello” → read the reply.
  5. If an Approval card appears, tap Deny (or Allow) — that only answers the home daemon.

This pairing is for the store-review demo home only. EnvoyHome Mobile is a thin client: the agent runs on the paired computer, not on the phone (Guideline 2.5.2).
