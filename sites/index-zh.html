工作原理

EnvoyMesh 遵循分层安全架构 —— 每个组件都有明确的边界和职责。

🌐

外交官 (网络)

libp2p 连接、消息解析、速率限制

🔑

身份与绑定

签名验证、信任等级、策略执行

⚙️

工作流与智能体核心

任务执行、AI 路由、工作流管理

📦

保险箱 API

知识检索、文档索引、安全存储

🧠

沙盒大脑

本地/远程模型执行、语义防火墙

安全管道

每条消息在交付前都要经过四次检查：

  1. 1 真的是你发来的吗？ (使用你的 Ed25519 密钥签名)
  2. 2 我信任你吗？ (信任等级：阻止、公开、推荐、直接)
  3. 3 这条消息允许吗？ (策略引擎 —— 发送者可以做什么？)
  4. 4 之前见过吗？ (无重放、无重复)

设计安全

安全是首要优先级，而非事后考虑。

🔑

自主身份

无需中央账户数据库。你的密钥，你的身份。

🛡️

策略信任

细粒度的信任等级和文档级权限。

📝

端到端审计

每一次操作都记录在审计日志中。

🔒

语义防火墙

模型前置过滤防止提示注入。

🚫

默认拒绝

只有经过批准的数据和能力可访问。

🔄

密钥轮换

支持撤销和密钥轮换。

几分钟内开始使用

在桌面或移动设备上安装 EnvoyMesh，开始构建你的私人网络。

git clone https://github.com/allenpeng0705/EnvoyMesh.git
cd EnvoyMesh
./scripts/setup.sh

# 运行
npm run node:dev # 启动 P2P 节点
npm run social:dev # 打开 http://localhost:5173
