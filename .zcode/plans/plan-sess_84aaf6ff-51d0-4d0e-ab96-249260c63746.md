# Plan: OpenClaw Extension/Plugin Management in EnvoyAI UI

## Current State
The existing `SkillManagerModal.tsx` supports ClawHub **skills** only (search, install, uninstall). OpenClaw has a full native **plugin/extension** system with enable/disable, inspect, update, npm/git/path install — but none of these are exposed in the UI.

## Goal
Extend the existing Skills & Plugins UI to also manage OpenClaw extensions/plugins: list with details, enable/disable, install from npm/git/path, uninstall, update.

## Architecture: Follow the existing 4-layer pattern

```
SkillManagerModal.tsx ──► useNodeService.tsx ──► json-rpc-router.ts ──► node-service-openclaw-plugins.ts
      (UI)                (RPC client)           (routing)              (calls OpenClaw library funcs)
```

### Layer 1: Types (`packages/api/src/`)

**New file: `packages/api/src/openclaw-plugin.ts`**

```typescript
export interface OpenClawPluginInfo {
  id: string;
  name: string;
  version?: string;
  description?: string;
  origin: "bundled" | "global" | "workspace" | "config";
  enabled: boolean;
  channels?: string[];
  tools?: string[];
  installSource?: string; // npm spec, git URL, or path
}

export interface OpenClawPluginDetail extends OpenClawPluginInfo {
  configSchema?: unknown;
  contributions?: unknown;
  installRecord?: {
    source: "npm" | "git" | "clawhub" | "marketplace" | "path";
    spec: string;
    version: string;
    installPath: string;
  };
}
```

### Layer 2: Node Service (`apps/node/src/`)

**New file: `apps/node/src/node-service-openclaw-plugins.ts`**

Implements plugin management by calling OpenClaw's TypeScript library functions directly (no CLI needed):

| RPC Method | OpenClaw Function | Returns |
|-----------|------------------|---------|
| `listOpenClawPlugins` | `buildPluginSnapshotReport()` → extract records | `OpenClawPluginInfo[]` |
| `inspectOpenClawPlugin` | `buildPluginInspectReport({ id })` | `OpenClawPluginDetail` |
| `enableOpenClawPlugin` | `enablePluginInConfig()` + persist config | `{ ok: boolean; message: string }` |
| `disableOpenClawPlugin` | `setPluginEnabledInConfig()` + persist config | `{ ok: boolean; message: string }` |
| `installOpenClawPluginFromNpm` | `installPluginFromNpmSpec()` + `recordPluginInstall()` | `{ ok: boolean; message: string }` |
| `installOpenClawPluginFromGit` | `installPluginFromGitSpec()` + `recordPluginInstall()` | `{ ok: boolean; message: string }` |
| `uninstallOpenClawPlugin` | `uninstallPlugin()` + persist config | `{ ok: boolean; message: string }` |
| `updateOpenClawPlugin` | `updateNpmInstalledPlugins()` + persist | `{ ok: boolean; message: string }` |

After enable/disable/install/uninstall, calls `reloadOpenClawConfigViaRuntime()` (existing function from `node-service-clawhub.ts`) to restart the gateway.

### Layer 4: UI (`apps/social/src/`)

**Extend `SkillManagerModal.tsx`** — Add a fourth tab "Extensions" alongside Search/Trending/Installed:

- **Installed extensions list**: Each row shows name, version, origin badge (bundled/global), enabled toggle switch, description
- **Expand row**: Shows full detail (channels, tools, install source, config schema)
- **Actions per extension**: Enable/disable toggle, uninstall button, update button (if update available)
- **Install bar**: Input field for npm spec (`@openclaw/memory-core`) or git URL (`git:https://...`), with an "Install" button
- **Bundled extensions** show as non-removable (no uninstall button), but can be enabled/disabled
