Step 25 — extract the public getPairingPayload method (151 lines)
which builds the QR-code pairing payload for mobile apps.

The class method collapses to a 1-line delegation. The runtime
takes a GetPairingPayloadContext with 11 accessors (getBridgeStatus,
getReachableMesh, getWsPort, getWsPath, getRelayPublicWsUrl,
getRelayBootstrapPeers, getProfile, deriveRelayWsUrl,
autoDiscoverRelayWsUrl, autoDiscoverRelayPeerId, setPairingToken).

The runtime body is a near-direct port of the original method
semantics:
  - Derives LAN IP from multiaddrs (skipping 127.0.0.1 loopback)
  - Resolves relay WebSocket URL with 3-state semantics (undefined =
    auto-discover, "" = disabled, "<url>" = explicit)
  - Generates fresh pairing token + sets issued-at timestamp
  - Builds wsUrl with target+token query params for relay case
  - Aggregates bootstrap peers (community libp2p, configured
    relays, WebSocket fallbacks)
  - Aggregates bootstrap preset names (deduplicated, home-configured
    first)
