Step 19 — extract getNodeConfig + updateNodeConfig to a runtime.

This is the largest single reduction so far:
  - getNodeConfig: 131 lines (env-var overrides + 60+ property copy)
  - updateNodeConfig: 265 lines (friend-matching-preferences validation
    + 60+ property copy)
Total: 396 lines of class code -> 10 lines (2 delegations) + 219 lines

The runtime is pure: takes a NodeConfigContext carrying the config
store, bridge status, relay-public-WS URL, bridge-config loaders,
and the local profile. The class methods collapse to one-liners.

returned. Friend-matching-preferences signed payloads are validated
inside the runtime via parseFriendMatchingPreferencesPayload, with
the same checks as the original (expiresAt in future, ownerId
matches).
